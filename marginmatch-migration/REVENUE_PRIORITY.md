# Revenue Priority — Cash Before Feature Count

Primary objective: collected contribution profit, not number of businesses built.

## Tier A — monetize first
1. Mattress Rescue — direct consumer transaction; already closest to paid fulfillment.
2. Lead Rescue — sell recovered qualified leads/appointments to service businesses.
3. Dead Quote Recovery — recover existing pipeline; easy ROI proof.
4. Estimate Chase — convert open estimates; easy ROI proof.
5. AI Procurement Broker — transaction spread/service fee when sourcing succeeds.

## Tier B — cross-sell after first customers
6. Past Customer Reactivation
7. Review + Referral Loop
8. Cancellation Slot Filler
9. AI Email Receptionist
10. Contractor Dispatch Desk

## Tier C — experimental portfolio
Youth/creator/affiliate, RFP alerts, intelligence, SEO audits, group bidding, etc.
Build cheaply, but do not divert launch capacity from Tier A until they show demand.

## Revenue gates
A product is not "launched" merely because code exists.
It must have:
- public/tenant onboarding
- clear offer and price
- payment path
- fulfillment workflow
- attribution
- support/exception path
- acquisition channel
- safety/compliance controls
- production health monitoring

## 7-day post-VPS objective
Day 0: bootstrap server, health/self-tests, backups, HTTPS.
Day 1: Mattress Rescue staging -> production cutover if tests pass.
Day 2: Lead Rescue + Dead Quote Recovery tenant onboarding/payment.
Day 3: email acquisition engine with approved templates and suppression.
Day 4: first bounded outbound acquisition batch.
Day 5: reply classification/follow-up + ROI dashboard.
Day 6: improve offer/pricing based on measured responses.
Day 7: scale only positive-signal acquisition; archive/no-spend weak channels.

No uncapped spend. No fake reviews/personas. No unauthorized bulk messaging.
